About Me

I build things
for the web.

I'm Anthony Michael, a self-taught Frontend Developer based in Nigeria. I build web and mobile interfaces that are fast, accessible, and production-grade, and I work closely with backend teams through Swagger-first REST API contracts.

Currently Frontend Lead on Laptope Institute of Technology (LIT), an ongoing EdTech platform where I lead a 7-person frontend team across Learner, Tutor, and Admin dashboards. Previously led frontend on EventPro, a multi-role SaaS event platform, and shipped ErrandGo, a React Native logistics app that won the Winnov8 Build Path Challenge.

My stack spans HTML5/CSS3/JavaScript to React, React Native, and Tailwind CSS, with REST API and JWT/OAuth integration. I've also built a full e-commerce frontend (FreshBasket Market) and my own product, Idea-Engne, from scratch.

When I'm not coding, I'm writing about web development I published HTML From Zero Vol.1 to help beginners actually understand the fundamentals.
