# tonydev-folio

Personal portfolio of **Anthony Michael (TonyDev)**, Frontend Developer based in Nigeria.

**Live:** https://tonydev-folio.netlify.app

## Featured work
- **LIT (Laptope Institute of Technology)** – Frontend Lead, React + Tailwind
- **ErrandGo** – React Native app, Winnov8 Build Path Challenge winner
- **EventPro** – Frontend Lead, 9-person bootcamp team, vanilla JS
- **FreshBasket Market**, **Idea-Engne** – personal projects

## Stack
Vanilla HTML, CSS and JavaScript (no build step). Fonts: Syne + Plus Jakarta Sans. Icons: Font Awesome (CDN). Contact form: Web3Forms. Hosted on Netlify.

## Run locally
```bash
npx serve .
```
Then open http://localhost:3000.

## Structure
```
index.html / index.css / index.js   – main page
blog.html, blog-eventpro.html       – blog
assets/images/                      – project images
assets/Anthony_Michael_CV.pdf       – downloadable CV
```
